# mall-customer-prediction-project
Mall Customer Analystics , ETL  Pipeline and Machine Learning Prediction
Mall Customer Analytics, ETL Pipeline & Machine Learning Prediction

📌 Project Overview

This project focuses on customer analytics, data processing, and machine learning-based customer churn prediction. It uses PySpark and data analysis techniques to process customer data and generate predictions that can help businesses understand customer behavior.

🎯 Project Objectives

- Analyze customer demographics and purchasing behavior.
- Process customer data using PySpark.
- Build an ETL workflow for data processing.
- Apply machine learning techniques for customer churn prediction.
- Generate prediction results and probability scores.
- Support data-driven business decisions.

🛠️ Technologies Used

- Python
- PySpark
- SQL
- Machine Learning
- Jupyter Notebook
- Databricks
- Git & GitHub

📊 Project Workflow

1. Data Ingestion: Load customer data from CSV files.
2. Data Processing: Read, clean, and prepare customer data using PySpark.
3. Feature Preparation: Prepare relevant features for machine learning.
4. Model Training: Train a machine learning model for churn prediction.
5. Model Evaluation: Evaluate model performance using appropriate metrics.
6. Prediction: Generate final churn predictions and probability scores.

📁 Project Structure

- "Ecommerce_Customer_Analytics_prediction.ipynb" — Main notebook containing data processing, analysis, and prediction code.
- "README.md" — Project documentation.

📈 Expected Business Benefits

- Identify customers who may be likely to leave.
- Understand customer behavior and purchasing patterns.
- Help businesses plan customer retention strategies.
- Support data-driven decision-making.

🚀 How to Explore the Project
